# 빅데이터 주제 실험실

ITM 527 빅데이터 실무 팀프로젝트 후보 주제 5개를 공공 API 실데이터로 1차 분석한 결과를 보여 주는 정적 사이트입니다.

- T1 우리 동네 가게 생존 예측 (서울 음식점·카페 인허가)
- T2 저평가 부동산 매입 후보 (국토부 연립다세대 매매·전월세)
- T3 빌라 전세 위험 조기경보 (국토부 연립다세대 전월세)
- T4 공공조달 입찰 인텔리전스 (조달청 용역 낙찰목록)
- T5 농산물 등급 가격차 (서울 가락시장 등급별 경락가)

데이터는 2026-09-27에 서울 열린데이터광장, 공공데이터포털(국토교통부·조달청) API로 받았습니다. 이 저장소에는 원본 데이터와 업체·개인 식별 정보를 올리지 않았고, `data/*.json`의 집계값만 있습니다.
